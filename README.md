# rada-tarot-bot

Клон Telegram-бота `@radataro_bot` («Рада · Таро»). Наш бот: `@zaria_taro_bot` («Заря · Таро»).
Код написан с нуля, тексты пересочинены, видео-кружок и фирменная картинка героини не копировались.

## Что умеет

| Раздел | Как работает |
| --- | --- |
| Онбординг | `/start`, имя или «Пропустить», нижняя клавиатура, меню тем |
| Карта дня | одна карта в сутки на человека, картинка и толкование, утром в `MORNING_HOUR` приходит сама |
| Да/нет | бесплатная карта, ответ ДА (прямая) или НЕТ (перевёрнутая), «Узнать подробнее» ведёт в платный расклад |
| Расклад | коллаж из трёх карт, счёт в Stars (`XTR`), после оплаты толкование и 3 уточнения; глубже - пять карт; ещё уточнения |
| Аркан, год, совместимость | по дате рождения, сложение цифр до 22 (сверено с оригиналом: 01.01.1990 -> Мир, год 2026 -> Повешенный, пара с 02.02.1991 -> Отшельник) |
| Полный разбор | счёт 350 ⭐ (250 платившим), статья в Telegraph, если задан `TELEGRAPH_TOKEN`, иначе текстом |
| Подарок, друг | подаренный расклад ссылкой `gift_<код>`, реферальная ссылка `ref_<id>` даёт расклад обоим |
| Служебное | `/terms`, `/paysupport`, `/forget`, «Мои разборы», утренние карты вкл/выкл, вопрос «сбылось?» через 3 и 7 дней, возврат звёзд при сбое выдачи |

## Библиотека толкований

`data/library/*.json`: 78 карт в двух положениях (карта дня, пояснение к да/нет, суть для раскладов), 22 аркана судьбы, 22 карты года, 22 аркана пары. Тексты написаны заранее без имён, имя бот подставляет заголовком. Поэтому карта дня, да/нет, аркан, год и совместимость работают без нейросети и ключей, а расклады, уточнения и полный разбор при отсутствии ключа или сбое провайдера собираются из этих же текстов (`rada/library.py`).
Проверка после правки текстов: `.venv/bin/python scripts/check_library.py`.

Не сделано: оплата криптой через @CryptoBot, пакет «3 расклада за 120 ⭐».

## Веб-админка

`admin.py` - отдельная служба на aiohttp, работает с той же SQLite-базой, что и бот. Правки лежат в таблице `content` поверх значений по умолчанию (`rada/texts.py`, `data/library`, `.env`). Бот перечитывает их раз в 3 секунды, поэтому после правки его не надо перезапускать.

| Раздел | Что меняется |
| --- | --- |
| Тексты и кнопки | все сообщения бота, надписи на кнопках (и нижней клавиатуры), темы, счета, описание и меню команд; проверка подстановок `{user}`, `{p3}` и длины, предпросмотр как в Telegram |
| Колода | картинка каждой из 78 карт и три толкования в двух положениях, фразы раскладов |
| Арканы | аркан судьбы (поля карточки и текст), карта года, аркан пары |
| Видео-кружки | ролики героини по сценариям (приветствие, карта дня, да/нет, расклад, оплата, аркан, год, совместимость, разбор, «сбылось?»); любое видео перекодируется ffmpeg в кружок 640x640 до 60 секунд |
| Профиль бота | аватар (сразу через `setMyProfilePhoto`), описание и команды кнопкой «Отправить в Telegram» |
| Цены и настройки | цены в звёздах, имя героини, час утренней карты, число уточнений; пустая правка возвращает значение из `.env` |
| Журнал | кто и что поменял, было/стало, откат к любому прежнему варианту |

Устройство:

- `rada/content.py` - реестр редактируемых ключей, проверка, функция `T(key, **kw)`, через которую бот берёт тексты. В любом тексте доступны общие подстановки: имя героини, ник бота, цены, час, число уточнений. Если в базе оказался текст с неизвестной подстановкой, бот возьмёт исходный.
- `rada/media.py` - каталог `MEDIA_DIR` (кружки `video/<сценарий>_*.mp4`, свои картинки карт `cards/<slug>.jpg`, аватар). При первом запуске кружки копируются туда из `assets/video`, дальше источник правды - `MEDIA_DIR`. Удалённые кружки уходят в `MEDIA_DIR/trash`.
- `webadmin/` - приложение, шаблоны Jinja2 и статика. Вход по логину и паролю (scrypt, регистр логина при входе не важен), сессия в cookie на 30 дней, CSRF-токен в каждой форме, проверка Origin, после 10 неудачных входов с одного адреса пауза 15 минут.
- Нижние кнопки бот узнаёт и по новой, и по исходной надписи: у людей может висеть старая клавиатура.

Логины:

```bash
.venv/bin/python admin.py adduser slava      # создать или сменить пароль, пароль печатается один раз
.venv/bin/python admin.py rename slava V   # новое имя, пароль прежний
.venv/bin/python admin.py deluser slava
.venv/bin/python admin.py users
.venv/bin/python admin.py serve --port 8770  # слушает 127.0.0.1, наружу через nginx
```

На сервере админка работает службой `rada-tarot-admin` под тем же пользователем, что и бот, nginx проксирует домен на `127.0.0.1:8770` (`client_max_body_size 200m` для видео). Для кружков нужен `ffmpeg` (`apt install ffmpeg`), без него принимаются только готовые квадратные MP4.

## Запуск

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt pytest
cp .env.example .env        # BOT_TOKEN, LLM_PROVIDER и ключ
.venv/bin/python scripts/fetch_cards.py   # картинки карт, один раз (без них рисуется заглушка)
.venv/bin/python bot.py
.venv/bin/python -m pytest -q
```

`LLM_PROVIDER`: `gemini` (как у оригинала) или `anthropic` дают живые толкования для платных раскладов; `stub` (по умолчанию) работает только на библиотеке. Цены, часовой пояс и число уточнений меняются в `.env` (см. `rada/config.py`).
Токен только в `.env` (в git не попадает), копия в vault `Pass/`.
